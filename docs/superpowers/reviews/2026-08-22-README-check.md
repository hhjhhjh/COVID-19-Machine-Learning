# README 문서 검진 기록

검진 대상은 저장소 루트의 `README.md`이다. 저장된 노트북 출력, 모델 메타데이터, CSV와 실제 파일 구조를 근거로 확인했다.

## 반영한 지적

- 확진자 코호트에서 `CLASIFFICATION_FINAL` 값이 고정된다는 설명을 삭제했다. 확진자 데이터에도 값 1, 2, 3이 존재하지만 모델 입력에서는 해당 열을 제외한다.
- 질환 변수는 코드 `98`을, 임신 변수는 코드 `97`, `98`, `99`를 `Unknown`으로 처리한다는 실제 구현 범위로 고쳤다.
- Logistic Regression뿐 아니라 LightGBM에서도 `AGE`를 표준화한다는 내용으로 고쳤다.
- 테스트 데이터에 임계값을 한 번만 적용했다는 표현을 삭제하고, 테스트 데이터는 임계값 선택에 사용하지 않았다는 검증 가능한 범위로 한정했다.
- EDA·전처리·모델링 노트북의 절대 경로와 전처리 CSV 저장 위치를 재실행 전에 바꿔야 한다는 안내를 추가했다.
- 설치 뒤 실행할 명령과 노트북 실행 순서를 추가했다.
- 실험 설계 표의 슬래시 나열을 각 비교 관계가 드러나는 문장으로 바꿨다.
- 개인 수행 범위, 평가 지표의 해석, 임계값과 리샘플링 결과를 구분해 읽을 수 있는 문장을 추가했다.

## 검진 결과

- `reviewer-grounding`은 수치와 파일 링크가 실제 저장 결과와 일치함을 확인했고, 사실 설명 다섯 건의 수정을 요청했다.
- `reviewer-fit`은 로컬 링크, 섹션 제목과 Markdown 공백 검사가 통과했음을 확인했고, 실행 안내와 표 문장 두 건의 수정을 요청했다.
- `reviewer-readability`는 처음 읽는 사람이 개인 기여, 실행 순서와 지표 의미를 더 빨리 파악하도록 네 건의 수정을 요청했다.

세 렌즈의 지적을 모두 반영했다. 검진에 적용한 원칙은 `CLEAR-COMM`, `FAIL-LOUD`, `FOCUSED`, `MEASURE-FIRST`, `NAME-ITEMS`, `NO-PRIORITY`, `PLAIN-KO`, `PROSE-FORM`, `READ-FLOW`, `SIMPLE`, `SSOT`, `SURGICAL`이다.
